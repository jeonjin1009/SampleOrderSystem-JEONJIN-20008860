# Improvement.md — 기능 개선 및 추가 목록

Phase별 구현 완료 후 사용성 및 품질 개선을 위해 추가하는 기능을 이 문서에 기록한다.
각 항목은 대상 Phase와 연결된 설계 문서(phase*.md)에도 반영한다.

---

## Phase 2 개선 사항

### IMP-001 — 시료 전체 조회 시 빈 목록 안내 메시지

| 항목 | 내용 |
|---|---|
| 대상 | `SampleView.showList()` |
| 현재 동작 | 등록된 시료가 없을 때 헤더만 출력되고 아무 내용도 나타나지 않음 |
| 개선 동작 | "등록된 시료가 없습니다." 메시지 출력 |
| 이유 | 빈 테이블은 오류인지 정상인지 구분이 어렵고 사용자 경험이 불명확함 |
| 관련 파일 | `docs/design/phase2.md`, `PRD.md` 해당 없음 (UI 동작 개선) |

### IMP-002 — 시료 삭제 기능 추가

| 항목 | 내용 |
|---|---|
| 대상 | `SampleController`, `SampleView`, `MainView` |
| 현재 동작 | 시료 관리 메뉴에 등록만 있고 삭제 기능 없음 |
| 개선 동작 | ID를 입력받아 해당 시료를 삭제 |
| 이유 | 잘못 등록된 시료나 더 이상 사용하지 않는 시료를 제거할 수 있어야 함 |
| 관련 파일 | `docs/design/phase2.md`, `PRD.md` 3.2절 (신규 기능으로 추가) |

**신규 시그니처:**
```java
// SampleController
public boolean deleteSample(String id);  // 없는 ID 삭제 시 IllegalArgumentException
```

**화면 흐름:**
```
[시료 삭제]
시료 ID > S001
삭제 완료: S001

-- 없는 ID인 경우 --
시료 ID > NONE
오류: 존재하지 않는 시료 ID입니다.
```

**주의 사항:**
- 현재는 해당 시료에 연결된 주문 존재 여부를 검증하지 않고 강제 삭제한다.
- 향후 Phase 3 주문 기능 구현 후 "진행 중인 주문이 있는 시료는 삭제 불가" 제약 추가를 검토한다.
